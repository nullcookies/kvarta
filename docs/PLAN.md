# План работ: лендинг обжарки кофе «Кварта» на Drupal CMS + Canvas

## 1. Что требует ТЗ

Источник: <https://tz.vitai.world/> («Тестовое: лендинг обжарки», веб-разработчик junior+).
Клиент — вымышленная обжарка «Кварта», Минск.

Обязательный состав лендинга:

| Блок | Что нужно из ТЗ |
| --- | --- |
| Кто они и почему свежесть важна | Аня и Дмитрий, партии по 5 кг с 2019, обжарка по четвергам, развоз по пятницам, зерно у клиента на 1–3 день |
| Ассортимент с ценами | Эфиопия Иргачеффе 32 BYN, Колумбия Уила 29 BYN, Бразилия Серрадо 26 BYN, дрип-пакеты 18 BYN, подписка 54 BYN/мес |
| Подписка | 2 пачки по 250 г в месяц, доставка бесплатно |
| Доставка и самовывоз | Минск, ул. Короля, 9; пн–пт 8:00–20:00, сб–вс 10:00–18:00; доставка по пятницам, от 50 BYN бесплатно |
| Контакты | телефон, адрес, часы |
| Форма заявки | имя, телефон, что интересует (подписка / разовый заказ / вопрос), комментарий |

Требования к форме и бэкенду:

1. телефон — белорусский номер, неверный не принимается, человек видит понятную подсказку;
2. повторная отправка того же номера в течение 10 минут (в том числе двойное нажатие) не создаёт вторую заявку;
3. заявка несёт атрибуцию: из какой рекламы, с какого объявления, с какой страницы;
4. если отправка не удалась — человек это видит и понимает, что делать;
5. хранилище заявок — на выбор, выбор объясняется в README.

Плюсы (не обязательны): дублирование заявки в Telegram-бот, превью ссылки в мессенджерах (OG-теги), уместные анимации.

## 3. Источники и инструменты

- **one_line_installer** (<https://www.drupal.org/project/one_line_installer>) — рецепт рабочего окружения:
  DDEV + Drupal CMS через Composer, `ai_best_practices`, агентные скиллы, экспорт конфигурации, guardrails.
  На Windows берём его схему (DDEV + `drupal/cms` + composer/recipe-unpack + config export), но без WSL-обвязки:
  DDEV на этой машине работает нативно через Docker Desktop.
- **drupal_devkit** (<https://www.drupal.org/project/drupal_devkit>) — реестр маркетплейсов скиллов.
  Подключаем маркетплейс `drupal-canvas-plugin` и работаем по скиллам:
  `using-drupal-canvas`, `canvas-project-setup`, `canvas-component-authoring`, `canvas-scaffolding`,
  `canvas-storybook`, `canvas-content-management`.
- **WordPal** (<https://www.drupal.org/project/wordpal>) — конвертер WP block themes в Drupal-темы для Canvas.
  Дизайн-источник: тема `the-coffee-shop` (галерея: <https://wordpal.tresbien.tech/#q=coffe>).

## 5. Архитектура решения

```
DDEV (kvarta)  →  https://kvarta.ddev.site
├── web/                      Drupal 11.4 (Drupal CMS 2.2.5)
│   ├── modules/custom/kvarta_lead/     эндпоинт POST /api/lead
│   └── themes/contrib/<coffee theme>/  тема, сконвертированная WordPal
├── canvas/                   Code Components (React 19 + Tailwind 4 + Storybook)
│   └── src/components/       секции лендинга «Кварта»
├── recipes/                  рецепты Drupal CMS (в т.ч. wordpal)
└── docs/                     план, логи, отчёты
```

### 5.1 Бэкенд формы (`kvarta_lead`)

- Маршрут `POST /api/lead`, JSON in / JSON out, доступ анонимный (публичная форма).
- Валидация белорусского телефона: нормализация к E.164 `+375XXXXXXXXX`,
  проверка кода оператора/города (25, 29, 33, 44, 17, 16, 22, 23, 25, 29, 33, 44, 51, 52, 53, 55, 56, 57, 58, 59, 62, 63, 64),
  понятные сообщения об ошибке на русском.
- Дедупликация 10 минут: нормализованный номер + окно 600 с, защита от гонки
  (lock backend + уникальный индекс `phone_hash + slot`), двойное нажатие даёт `duplicate: true`.
- Атрибуция: `utm_*`, `gclid/yclid/fbclid`, referrer, страница входа (first-touch) и страница отправки, user-agent, IP (хеш).
- Ошибки: 4xx/5xx с `{"ok":false,"errors":{...},"message":"..."}` — фронт показывает текст и подсказку.
- Антиспам: flood control по IP + honeypot-поле.
- Telegram (плюс): дублирование заявки при наличии `KVARTA_TELEGRAM_TOKEN`/`KVARTA_TELEGRAM_CHAT_ID` в окружении.

### 5.2 Фронтенд

- Лендинг — Canvas-страница `/` (path alias), собранная из Code Components.
- Компоненты: `section`, `hero`, `eyebrow`, `heading`, `text`, `button`, `feature_list`+`feature_item`,
  `product_grid`+`product_card`, `info_columns`, `subscription_band`, `lead_form`.
- Стили — токены кофейной темы в `global.css` (`@theme`), CVA-варианты, никаких hex в компонентах.
- Анимации: мягкое появление секций на скролле, `prefers-reduced-motion` уважается.
- OG-превью: метатеги Canvas + картинка 1200×630, сгенерированная PHP GD в контейнере.

## 6. Порядок выполнения

1. Разведка ТЗ и источников, план (этот файл).
2. DDEV-проект + Drupal CMS (`ddev composer create-project drupal/cms`), установка сайта.
3. Скиллы drupal_devkit: маркетплейс `drupal-canvas-plugin` → `.agents/skills`.
4. WordPal: `drupal/wordpal`, конвертация `the-coffee-shop`, включение темы.
5. Canvas: `npx @drupal-canvas/create` → `canvas/`, `.env`, OAuth-клиент `canvas_cli`,
   JSON:API write mode, page regions, `jsonapi_menu_items`.
6. Модуль `kvarta_lead` + тесты эндпоинта (curl-сценарии из ТЗ).
7. Компоненты лендинга + Storybook, загрузка на сайт, сборка Canvas-страницы.
8. Контент «Кварта»: тексты, цены, фото (свободная лицензия), меню.
9. Проверки: сценарии формы (валидация/дубль/ошибка/атрибуция), Lighthouse mobile.
10. Репозиторий: пошаговые коммиты, README, лог работы с ИИ.

## 7. Допущения (фиксируются в README)

- Публичный хостинг не поднимаем: среда — локальный DDEV по требованию заказчика; деплой описан.
- Telegram-дублирование включается переменными окружения и по умолчанию выключено (нет боевого бота).
- Фото — свободная лицензия (Unsplash/Pexels) или сгенерированные; логотип «КВАРТА» — текст.
- Заявки хранятся в таблице Drupal (`kvarta_lead`), а не в файле/SQLite: сайт уже работает на MariaDB,
  нужны транзакции, уникальные индексы и удобная выгрузка через Views/Drush.
